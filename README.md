#  Spam Mail Detector (Machine Learning)

A simple **Spam Mail Detection** project built using Python and Scikit-learn.  
This project trains a machine learning model to classify messages/emails as **Spam** or **Not Spam (Ham)**.

---

##  Features

- Load and explore dataset (`combined_data.csv`)
- Clean and preprocess text data
- Convert text into numeric features (Vectorization)
- Train a machine learning classification model
- Evaluate performance (Accuracy, Confusion Matrix, etc.)
- Predict whether a message is **Spam** or **Ham**

---

##  Download Dataset from Kaggle

This notebook expects a dataset file named:

 **`combined_data.csv`**

###  Option 1: Manual Download (Easy)

1. Go to Kaggle and download a spam detection dataset  
2. Extract the `.zip` file  
3. Place the CSV file in the same folder as the notebook  
4. Rename the CSV file to: combined_data.csv
